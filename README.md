# Microservices Learning Journey (Spring Boot)

**A concise, resume-style repository** showcasing hands-on learning and practical experience in **Microservices Architecture** using **Spring Boot, Cloud-Native patterns, Docker, Kubernetes, and Event-Driven systems**.

---

## 📌 Summary

* Designed and built **microservices-based systems** using Spring Boot & Spring Cloud
* Applied **DDD principles** to define service boundaries and right-size microservices
* Implemented **resilience, security, observability**, and **event-driven architecture**
* Containerized services with **Docker** and deployed to **Kubernetes**
* Explored **cloud-native & 15-Factor App** best practices

---

## 🛠️ Tech Stack

**Backend:** Java, Spring Boot, Spring Cloud  
**Databases:** MySQL  
**Messaging:** RabbitMQ, Kafka  
**DevOps:** Docker, Kubernetes, Helm  
**Cloud-Native:** Config Server, Gateway, Service Discovery  
**Observability & Security:** Prometheus, Grafana, OAuth2, mTLS
